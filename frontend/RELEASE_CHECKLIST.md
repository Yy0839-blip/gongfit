# 공핏 MVP 출시 체크리스트

## 핵심 사용자 흐름
- [x] 앱 시작 시 로컬 프로필 불러오기
- [x] 프로필 저장
- [x] 채용공고 텍스트 입력
- [x] 공고 파싱 API 호출
- [x] 프로필 기반 적합도 API 호출
- [x] 점수/강점/보완점/추천 결과 표시
- [x] 결과에서 AI 상담으로 이동
- [x] AI 챗봇 빈 입력 방지
- [x] API 타임아웃/네트워크 오류 처리

## 출시 전 필수 확인
- [ ] 운영 API URL을 `--dart-define=GONGFIT_API_URL=...`로 지정
- [ ] Android/iOS 실기기에서 API 연결 테스트
- [ ] 백엔드 운영 배포 및 CORS/HTTPS 확인
- [ ] 개인정보처리방침/이용약관/문의 채널 준비
- [ ] 앱 아이콘/스토어 설명/스크린샷 준비
- [ ] 실제 공고 10건 이상으로 분석 QA
- [ ] AI 답변 품질 및 비용 점검

## 데모
1. 프로필 설정
2. 공공기관 채용공고 붙여넣기
3. `공핏 분석 시작`
4. 적합도 점수 확인
5. 강점/보완점 확인
6. `공핏 AI에게 물어보기`
